## 技术栈

### 前端

- React 18 + Vite 5
- TailwindCSS 3
- Lucide React（图标）
- Axios（HTTP 请求）
- React Router DOM（路由）

### 后端

- Node.js 20
- NestJS 10
- TypeORM（ORM 框架）
- SQLite（数据库）
- JWT（鉴权）
- pdf-parse、mammoth（文档解析）

### 运维

- Docker
- Docker Compose

### 版本控制

- GitHub

### 全文检索

- Elasticsearch

### AI Agent

- LLM（大语言模型）

## 功能模块

### 1. 认证模块

- 用户注册
- 用户登录
- JWT 令牌验证

### 2. 文档管理

- 文档上传（支持 PDF、DOCX、MD、TXT）
- 文档列表展示
- 文档详情预览
- 文档搜索
- 文档删除

### 3. 分类管理

- 分类创建
- 分类列表（树形结构）
- 分类筛选
- 拖拽排序

### 4. 标签管理

- 标签创建
- 标签筛选
- 文档标签关联
- 拖拽排序
