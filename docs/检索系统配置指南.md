# 知识库检索系统配置指南

## 系统概述

检索系统基于 Elasticsearch 实现，支持：
- 文档标题、内容、描述的全文检索
- 附件内容检索（PDF、DOC、DOCX、TXT 等）
- 音视频文件语音转文字检索
- PDF 文档 OCR 识别

## 快速开始

### 1. 启动 Elasticsearch

```bash
# 方式一：使用启动脚本（推荐）
./start-search.sh

# 方式二：手动启动
docker-compose -f docker-compose.elasticsearch.yml up -d
```

### 2. 验证 Elasticsearch 是否启动成功

访问 http://localhost:9200，应看到类似以下 JSON：

```json
{
  "cluster_name" : "docker-cluster",
  "status" : "green",
  ...
}
```

### 3. 配置 API Key

登录知识库系统后，进入「检索配置」页面：

1. **OpenAI API Key（Whisper 语音转文字）**
   - 获取地址：https://platform.openai.com/api-keys
   - 用途：将音视频文件中的语音转换为文字

2. **火山引擎 API Key（OCR 文字识别）**
   - 获取地址：https://console.volcengine.com/
   - 创建 OCR 应用获取 App ID 和 API Key
   - 用途：PDF 文档 OCR 识别

### 4. 建立索引库

在「检索配置」页面：

- **重建全部索引**：为所有文档建立索引
- **按分类索引**：选择特定分类进行索引

索引过程会在后台进行，较大规模的文档库可能需要较长时间。

## API 说明

### 搜索 API

```
GET /api/search?keyword=关键词&categoryId=可选的分类ID
```

响应示例：

```json
[
  {
    "id": "1",
    "title": "文档标题",
    "content": "文档内容...",
    "description": "文档描述",
    "categoryName": "分类名称",
    "tags": ["标签1", "标签2"],
    "score": 1.5,
    "highlights": {
      "title": ["<em>关键词</em>"],
      "content": ["...包含<em>关键词</em>的片段..."]
    }
  }
]
```

### 索引管理 API

```bash
# 索引单个文档
POST /api/search/index/:documentId

# 重建全部索引
POST /api/search/index-all

# 按分类索引
POST /api/search/index-category/:categoryId

# 获取索引状态
GET /api/search/stats

# 删除文档索引
DELETE /api/search/document/:documentId
```

## 支持的文件类型

| 文件类型 | 处理方式 | 说明 |
|---------|---------|------|
| PDF | pdf-parse / OCR | 提取文本或图片文字 |
| DOC/DOCX | mammoth | 提取 Word 文档文本 |
| TXT | 直接读取 | 直接读取文件内容 |
| MD | 直接读取 | Markdown 文件内容 |
| HTML | 直接读取 | HTML 文件内容 |
| MP3/MP4/WAV | Whisper API | 语音转文字 |

## 注意事项

1. **首次使用**：请先在「检索配置」页面配置 API Key
2. **索引更新**：文档更新后需要重新建立索引
3. **性能考虑**：大量文档的索引过程可能较慢，建议分批进行
4. **存储空间**：Elasticsearch 会占用一定磁盘空间

## 常见问题

### Q: Elasticsearch 启动失败？

```bash
# 检查 Docker 是否运行
docker ps

# 查看 Elasticsearch 日志
docker logs knowledge-base-elasticsearch
```

### Q: 索引后搜索不到结果？

1. 检查 Elasticsearch 是否正常运行
2. 确认 API Key 已正确配置
3. 尝试重新建立索引

### Q: 音视频文件无法转文字？

1. 确认 OpenAI API Key 已配置
2. 检查音视频文件格式是否支持
3. 查看后端日志确认转录过程

## 扩展配置

### 调整 Elasticsearch 内存

编辑 `docker-compose.elasticsearch.yml`：

```yaml
environment:
  - "ES_JAVA_OPTS=-Xms1g -Xmx1g"  # 调整内存大小
```

### 启用 Kibana

Kibana 是 Elasticsearch 的可视化界面：

```bash
docker-compose -f docker-compose.elasticsearch.yml up -d kibana
```

访问 http://localhost:5601 查看。
